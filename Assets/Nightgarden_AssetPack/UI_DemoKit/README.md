# 夜园 Demo UI 素材包

参考 Brotato 的四商品卡与波间整备思路，按本项目要求重排。没有使用原游戏贴图。全部数值为模板；本包提供美术、布局和配置示例，不是已接入的商店或战斗系统。

## 内容

- `Art/background.png`：独立无文字主菜单背景。
- `Components`：30 个独立 PNG 与可编辑 SVG，包含按钮的普通/悬停/按下/禁用状态、面板、选择高亮、锁、刷新、合成和关闭图标。
- `Screens`：15 张 1600×900 PNG 预览及对应 SVG 源布局：主菜单、选人、初始武器、商店、刷新确认、合成、升级、受击与掉落、排行榜、登录、注册、战斗 HUD、暂停、失败结算、胜利结算。
- `Art/stats.png`：攻击速度、吸血、回复速度、移动速度、物理伤害、魔法伤害、防御、幸运、生命上限，共 9 个属性图标。
- `Art/currency.png`：钱包图标与 +1 / +5 / +10 地图掉落，共 4 个图标；采用琥珀种子主题。
- `Art/hit.png`：4 帧受击闪光，12 FPS、单次播放。无血腥效果。
- 5 名角色的头像切片使用已有空手角色第一帧；武器与饰品图集复用已有素材。`sprites.json` 给出 54 个命名区域，PNG 原图未改动。
- `Audio`：复用 7 个音效。点击/悬停/不可用/购买/合成升级/命中/受伤均已有，不重复制作。

## 如何查看

双击 `index.html`，可切换界面预览、播放四帧受击和试听音效。页面是素材浏览器，商品按钮与背包为布局示例，不实际购买或存档。
原图集可能在忽略 alpha 的查看器中显示暗色边缘区域，请在支持透明度的引擎中查看。

## Unity 导入

1. 将整个 `UI_DemoKit` 文件夹复制到工程的 `Assets` 下。
2. 执行 `Tools → Nightgarden → Import UI Demo Kit`。工具按实际尺寸命名切片，并为组件设置建议的九宫格边距。
3. Canvas 建议使用 Scale With Screen Size，参考分辨率 1600×900。带边距的面板/卡框/按钮 Image 可设为 Sliced；肖像框保持宽高比。
4. 单独使用背景和 `Components`，叠加 TextMeshPro、Image 与 Button。不要把整张 `Screens` 预览图当正式游戏 UI。文字、价格、属性、I/II/III 标记均应作为运行时文本。
5. Button 的 Transition 选 Sprite Swap，绑定普通、悬停、按下、禁用四张组件图。
6. `Data/demo_config.json` 是可自定义模板，未自动绑定运行时代码。`sprites.json` 使用左上角像素坐标，工具已换算 Unity 左下角坐标。

## 商店规则与布局

- 上方恰好 4 个商品卡。底部左侧角色头像、旁边两排饰品、最右侧 2×3 武器槽，共 6 把。
- 商品与背包之间新增常驻的“当前属性”栏，一次显示全部 9 项属性。值为含装备加成的角色属性示例，实际应在购买、合成或更换装备后重新计算；百分比加成与固定数值分开显示。
- 武器 I/II/III 对应鼠尾草绿/青蓝/灰紫卡框。商品卡和已装备武器槽使用一致等级颜色，同时显示罗马数字，避免仅靠颜色识别。
- 饰品使用独立的普通/稀有/史诗框，示例沿用三色；稀有度与武器等级是两套字段。
- 两把相同 ID、相同等级的武器消耗后合成一把下一级；最高 III 级。不同武器或不同等级不能合成。
- `allowed_levels` 支持 `[1,2,3]`、`[2,3]` 或 `[3]`，分别对应常规、II 级起始、仅 III 级武器。商店抽取、合成结果都应检查此字段。
- 每次购买检查货币与装备容量；合成可释放一个武器槽。模板价格/伤害/间隔/回血等请自行调整。
- 刷新消耗种子，锁定商品保留。幸运在模板中只提供属性图标及字段，概率算法由你定义。
- 主角示例 3 个可用、2 个锁定；解锁条件可替换。初始武器页只展示 6 把。

## 受伤特效与死亡掉钱

- 新增闪光按 `hit_0 → hit_1 → hit_2 → hit_3` 播放；12 FPS，约 0.33 秒后隐藏/回收。四帧同画布，中心对齐，不独立紧裁。
- 角色受伤可另外短暂染白或染红（建议约 0.08 秒），后恢复原色；不是永久改角色贴图。
- 已有 `Nightgarden_AssetPack/Generated/Particles/damage_splat.prefab`、`hit_sparks.prefab`、`enemy_death.prefab` 分别用于受击飞溅、命中火花、死亡消散。本小包不重复复制旧 Prefab，避免在已有工程产生重复 GUID；它们在原动画包中。
- 怪物死亡后生成 `seed_1 / seed_5 / seed_10`，拾取数值与图标分开保存。建议抛出后落地，小幅上下浮动，进入拾取范围后吸向角色；这些是接入建议，尚未新增掉落运行时代码。
- 通常一次受伤播放命中声或受伤声之一，死亡时改播原有死亡声，避免多层堆叠。

## 排行榜

主界面新增排行榜按钮；在 HTML 预览中可直接点击进入，再点击返回主界面。提供名次、玩家、角色头像、分数、最高波次及存活时间，前三名强调显示，个人最佳行高亮。
`Data/leaderboard_example.json` 为本地榜单占位数据，按分数降序排列；尚未连接本地存档或在线排行服务。Unity 中将主菜单按钮绑定到排行榜面板，返回按钮关闭面板。

## 登录与注册

新增账号登录与注册模板，及输入框普通/聚焦/错误三态组件。登录包含账号和密码，注册包含账号、密码及确认密码。输入框的标签与内容不烘焙在组件 PNG 中。
HTML 预览默认展示登录页，可点击登录进入主界面，或打开注册，再返回登录。输入栏为静态占位，不接受账号密码；预览点击不执行身份验证、不创建账号、不保存凭据。Unity 可将输入框组件用于 TMP_InputField，账号服务和存储由项目后续接入。

## Demo 必要页面补全

新增战斗 HUD（生命、经验、等级、波次、倒计时、货币、暂停）、暂停菜单、胜利与失败结算。复用场地、经验掉落和角色，不新增角色数量。新增 bar_frame、health_fill、xp_fill、pause_icon 四个组件。血条/经验条填充用 Image Filled，不应缩放整张场景图。
预览中已连接进入游戏→选人→初始武器→战斗→暂停/继续，以及结算的重开、排行榜与返回入口；仍是静态页面流程模板。胜负由顶部导航选择示例页，未实现战斗判定。
